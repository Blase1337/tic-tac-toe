# Tic-Tac-Toe
A classic Tic Tac Toe game implemented with HTML, CSS, and JavaScript. The project uses a modular approach (factories + IIFE) to minimize global code while keeping logic organized. It demonstrates handling game state, player turns, and win conditions.

## Features
- Two-player gameplay in the browser

- Dynamic board rendering with JavaScript

- Modular code structure (factories and IIFE pattern)

- Clear UI updates for turns and results
